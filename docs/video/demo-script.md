# MeetGrid 발표 영상 구성안

목표 길이: 2분 40초 이내

## 0:00 - 0:20 소개

안녕하세요. 제가 만든 앱은 MeetGrid입니다. 친구들과 약속 시간을 정할 때 각자 가능한 시간을 입력하면, 가장 많이 겹치는 시간대를 추천해 주는 Flutter 앱입니다.

## 0:20 - 0:45 문제 설명

보통 단체 채팅방에서 약속 시간을 정하면 여러 사람이 가능한 시간을 메시지로 보내고, 그걸 직접 비교해야 합니다. MeetGrid는 이 과정을 그룹, 초대코드, 시간표, 추천 결과 흐름으로 단순화했습니다.

## 0:45 - 1:15 그룹 생성과 초대코드

그룹 탭에서는 새 약속 그룹을 만들 수 있습니다. 그룹을 생성하면 초대코드가 발급되고, 친구는 이 코드를 입력해서 같은 그룹에 참가할 수 있습니다.

## 1:15 - 1:55 가능한 시간 입력

시간표 탭에서는 오늘부터 30일 동안의 날짜가 표시됩니다. 날짜를 고른 뒤 가능한 시간대를 누르면 내 가능 시간이 저장되고, 각 시간대에 몇 명이 가능한지도 함께 확인할 수 있습니다.

## 1:55 - 2:25 겹치는 시간 확인

결과 탭에서는 많이 겹치는 시간대를 추천 순서로 보여줍니다. 예를 들어 4명 중 4명이 가능한 시간은 가장 좋은 후보가 되고, 체크 버튼으로 약속 시간을 확정할 수 있습니다.

## 2:25 - 2:40 구현 요약

앱은 Flutter와 Dart로 만들었고, 상태 관리는 Provider 기반으로 구성했습니다. Firebase Authentication과 Cloud Firestore를 연결해 사용자, 그룹, 시간 선택 데이터를 저장하도록 구현했습니다.

## 2:40 마무리

MeetGrid는 친구끼리 약속 시간을 더 빠르고 명확하게 정하기 위한 앱입니다. 이상으로 시연을 마치겠습니다.
