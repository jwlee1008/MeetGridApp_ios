# MeetGrid 발표 영상 구성안

목표 길이: 2분 40초 - 3분 10초

## 0:00 - 0:20 소개

안녕하세요. 제가 만든 앱은 MeetGrid입니다. 친구들과 약속 시간을 정할 때 각자 가능한 시간을 입력하면, 가장 많이 겹치는 시간대를 자동으로 찾아주는 iOS 앱입니다.

## 0:20 - 0:45 문제 설명

보통 단체 채팅방에서 약속 시간을 정하면 여러 사람이 가능한 시간을 메시지로 보내고, 그걸 직접 비교해야 합니다. MeetGrid는 이 과정을 그룹, 초대코드, 시간표, 추천 결과 흐름으로 단순화했습니다.

## 0:45 - 1:15 그룹 생성과 초대코드

첫 화면에서는 그룹을 만들 수 있습니다. 그룹을 생성하면 초대코드가 발급되고, 친구는 이 코드를 입력해서 같은 그룹에 참가할 수 있습니다. Firebase 익명 로그인을 사용해서 별도 회원가입 없이 시작할 수 있게 했습니다.

## 1:15 - 1:55 가능한 시간 입력

시간 탭에서는 월요일부터 일요일까지 시간표가 표시됩니다. 사용자는 가능한 시간 칸을 눌러 체크할 수 있습니다. 선택한 시간은 Firebase Firestore에 저장되도록 구현했습니다.

## 1:55 - 2:30 겹치는 시간 확인

결과 탭에서는 각 시간대에 몇 명이 가능한지 숫자와 색상으로 보여줍니다. 예를 들어 4명 중 4명이 가능한 시간은 가장 강하게 표시되고, 앱이 최고 추천 시간을 확정할 수 있게 버튼을 제공합니다.

## 2:30 - 2:55 구현 요약

앱은 SwiftUI로 UI를 만들었고, 상태 관리는 Observation을 사용했습니다. Firebase Authentication의 익명 로그인과 Cloud Firestore를 연결해서 그룹과 시간 선택 데이터를 저장합니다.

## 2:55 - 3:10 마무리

MeetGrid는 친구끼리 약속 시간을 더 빠르고 명확하게 정하기 위한 앱입니다. 이상으로 시연을 마치겠습니다.
